# typingEng

**따라 치면서 익히고, 직접 써보면서 내 것으로 만드는 영어 학습 앱**

쉬운 영어 소설이나 채팅 대화를 한 줄씩 따라 타이핑하면서 표현을 손에 익히고, 이어서 한국어 뜻만 보고 같은 내용을 영어로 직접 써본 뒤 AI 첨삭을 받는 데스크톱 앱입니다.
문장 생성과 첨삭은 로그인된 **Claude Code CLI**가 맡기 때문에 API 키가 필요 없습니다.

---

## 학습 흐름

```
① 설정            ② 따라치기                    ③ 직접 쓰기
레벨·장르·주제  →  영어 한 줄씩 타이핑        →  한국어 뜻만 보고 영작
(A1~B2)           글자별 정오 표시, WPM/정확도     Claude가 교정 + 한국어 피드백
```

1. **설정** — 레벨(A1 / A2 / B1 / B2), 장르(채팅 / 소설), 주제(자유 입력)를 고르면 Claude가 8~12줄의 영어 문장과 한국어 뜻을 만듭니다.
2. **따라치기**
   - 한 줄씩 따라 칩니다. 맞은 글자는 초록, 틀린 글자는 빨강, 남은 글자는 회색으로 표시됩니다.
   - 줄 끝까지 친 뒤 Enter를 누르면 다음 줄로 넘어갑니다.
   - 채팅일 때는 화자 이름(`Mia:`)은 라벨로만 보여주고 **대사만** 타이핑합니다.
   - WPM과 정확도가 표시되고, 틀린 단어는 따로 모아둡니다.
3. **직접 쓰기**
   - 방금 친 문장의 **한국어 뜻만** 보고 영어로 다시 씁니다.
   - Claude가 교정문, 틀린 부분별 설명(`원래 표현 → 고친 표현 + 이유`), 격려 피드백을 줍니다.
   - 원문은 "모범 답안"으로 함께 보여줍니다. 원문과 똑같이 쓰지 않아도 자연스럽고 맞는 영어면 인정합니다.

### 유튜브로 연습하기 (문장마다 듣고 → 멈추고 → 따라 치기)
1. 첫 화면 **유튜브로 연습**에 링크를 넣고 **시작**을 누릅니다. 영어 자막이 없으면 자동 생성 자막을 씁니다.
2. 자막은 약 10줄 세트로 나뉩니다. Claude가 세트의 구두점을 되살리고 문장마다 한국어 뜻을 붙입니다. 각 문장에는 자막의 단어별 시각을 맞춰 영상 구간을 붙입니다.
3. 브라우저에 플레이어 페이지가 열립니다. 처음 한 번 **▶ 클릭해서 연결**을 누르세요. 브라우저 자동재생 제한 때문입니다.
4. 문장 구간이 재생되고 끝에서 멈춥니다. 따라 친 뒤 Enter를 누르면 다음 문장이 재생됩니다.
   - 빈 칸에서 Enter를 누르거나 **↻ 다시 듣기**를 누르면 같은 문장을 다시 듣습니다.
   - **0.75배속**으로 천천히 들을 수 있습니다.
5. 세트가 끝나면 직접 쓰기와 첨삭으로 넘어갑니다. **다음 세트 ▶**로 영상 끝까지 이어 갈 수 있습니다.

> 영상 주인이 다른 사이트 재생(임베드)을 막아 둔 영상은 플레이어에서 재생되지 않습니다.

#### YouTube 요청 제한(HTTP 429)을 피하는 방식
- **영상당 자막 요청 1번:** 먼저 `yt-dlp -J`로 자막 목록만 확인하고 트랙 하나를 고릅니다. 자동 자막 원본(`en-orig`)이 1순위이고, 없으면 사람이 단 영어 자막입니다. 그다음 받은 정보 파일(`--load-info-json`)을 재사용해 그 트랙만 받기 때문에 페이지를 다시 요청하지 않습니다.
- **한 번 받은 영상은 다시 요청하지 않습니다.** 자막과 변환한 세트는 보관함에 저장됩니다.
- **Chrome 로그인 쿠키 사용(기본 켜짐):** Chrome에 YouTube 로그인이 되어 있으면 로그인 사용자로 요청합니다. 로그인 사용자는 익명 요청보다 제한이 훨씬 느슨합니다. 처음 한 번 macOS 키체인 허용 창이 뜹니다. 쿠키를 읽지 못하면 쿠키 없이 다시 시도합니다.
- **자동 재시도:** 그래도 429가 나면 10초, 30초 쉬었다가 다시 시도합니다.

### 보관함 (자동 저장)
- Claude가 만든 AI 문장, 유튜브 영상의 자막·변환한 세트·진행 위치는 모두 `~/.typing_eng_library.json`에 자동 저장됩니다.
- 첫 화면 **보관함**에서 다시 열면 Claude를 부르지 않고 바로 시작합니다. 영상은 **이어하기**로 마지막 세트부터 이어 갑니다.
- 이미 보관함에 있는 영상 링크를 다시 넣어도 자막을 다시 받지 않습니다.

누적 줄 수, 최고 WPM, **자주 틀린 단어**는 저장되어 첫 화면에 보입니다.

## 실행 방법

### 준비물
- Rust (edition 2024, 1.85 이상)
- [Claude Code](https://claude.com/claude-code) CLI 설치 및 로그인
  ```bash
  claude   # 처음 한 번 실행해서 로그인
  ```
- (유튜브 기능을 쓸 때) [yt-dlp](https://github.com/yt-dlp/yt-dlp)
  ```bash
  brew install yt-dlp
  ```

### 실행
```bash
git clone https://github.com/1ncarnati0n/typingEng.git
cd typingEng
cargo run --release
```

### 테스트
```bash
cargo test                 # 타이핑 로직 단위 테스트 (사용량 없음)
cargo test -- --ignored    # 실제 claude CLI / yt-dlp 호출 확인 (Claude 사용량·네트워크 사용)
```

## 기술 구성

| 영역 | 사용 기술 |
|---|---|
| 언어 | Rust (edition 2024) |
| GUI | [iced](https://iced.rs) 0.14 — Elm 아키텍처(State / Message / update / view), TokyoNight 테마 |
| AI | Claude Code CLI (`claude -p`) + JSON Schema 구조화 출력 |
| 직렬화 | serde, serde_json |
| 저장 | `~/.typing_eng.json` (통계), `~/.typing_eng_library.json` (보관함) |
| 영상 | yt-dlp(자막), YouTube IFrame API(브라우저 재생) — 앱 ↔ 브라우저는 std `TcpListener` |

의존성은 `iced`, `serde`, `serde_json` 세 개뿐입니다.

### 프로젝트 구조

```
src/
├── main.rs     iced 앱: 상태, 메시지, 화면 3개(설정 / 따라치기 / 쓰기)
├── store.rs    통계·보관함 JSON 저장 (임시 파일에 쓰고 rename)
├── player.rs   127.0.0.1 미니 HTTP 서버 — 브라우저 플레이어에 "구간 재생" 명령 전달
├── player.html YouTube IFrame API 플레이어 페이지 (구간 끝에서 자동 멈춤)
├── claude.rs   Claude CLI 호출: generate_lines(), lines_from_transcript(), review_writing()
├── youtube.rs  yt-dlp로 영어 자막 받기, VTT → 단어별 시각, 세트 나누기, 문장↔영상 구간 맞추기 + 테스트
└── typing.rs   순수 로직: 글자별 정오 판정, WPM, 틀린 단어 추출 + 단위 테스트
```

### Claude 연동 방식

HTTP API나 API 키 대신, 사용자가 이미 로그인해 둔 Claude Code CLI를 하위 프로세스로 실행합니다.

```bash
claude -p "<prompt>" \
  --output-format json \
  --json-schema '<JSON Schema>' \
  --system-prompt "<튜터 역할>" \
  --tools "" --strict-mcp-config \
  --no-session-persistence --effort low
```

- **구조화 출력:** `--json-schema`로 응답 형태를 고정하고, 결과 이벤트의 `structured_output` 필드를 serde로 바로 역직렬화합니다.
  - 문장 생성: `{ lines: [{ speaker, en, ko }] }`
  - 첨삭: `{ corrected, feedback_ko, errors: [{ original, fix, why_ko }] }`
- **가볍고 독립적인 호출:**
  - 도구와 MCP를 끄고, 세션 기록을 남기지 않습니다.
  - 임시 폴더에서 실행해서 다른 프로젝트의 `CLAUDE.md`를 읽지 않습니다.
- **UI가 멈추지 않게:** CLI 호출은 블로킹이므로 별도 스레드에서 실행하고, `oneshot` 채널로 결과를 받아 iced `Task`로 전달합니다.
- **오류 처리:** CLI가 없으면 설치·로그인 안내를, CLI 오류(로그인 만료 등)는 그 메시지를 화면에 보여줍니다.

### 타이핑 측정
- **글자 판정:** 바이트가 아닌 `char` 단위로 비교해서 유니코드에도 안전합니다.
- **WPM:** 표준 공식인 `(맞은 글자 수 / 5) / 분`을 씁니다.
- **정확도:** 끝낸 줄들의 `맞은 글자 / 전체 글자`입니다.
- **틀린 단어:** 틀린 글자가 하나라도 있는 단어를 소문자로, 구두점을 빼고 모아 누적합니다.
